RustFS 1.0.2

S3 object storage in Rust (Apache 2.0), a MinIO alternative: 1.0.2 (Oct 16) caps memory on multipart copies, speeds up multipart I/O and fixes ListParts pagination; 1.0.3 (Oct 17) only touches the console. Found via the rustfs/rustfs GitHub release.

TrueNAS 27 RC.1

First RC of TrueNAS 27 (formerly TrueNAS 26), released Oct 6: OpenZFS 2.4.4, kernel 6.18 and a native S3 service in early access, where each bucket is a ZFS dataset (snapshots, quotas, replication). Test on a lab NAS; stable expected early December.

Duplicati 2.4.0.1

Encrypted, deduplicated backup to NAS, S3 or cloud: stable 2.4.0.1 (Oct 7) makes restores more reliable (it continues if one file fails), as well as cancelling and the new sync mode, and hardens login and remote control, now Synology DSM compatible.
